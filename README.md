# arduino-bubble-sort

Visualisierung des Bubble-Sort-Algorithmus auf einem 16×2-I²C-LCD mit einem Arduino.

## Hardware

- Arduino Uno oder Nano
- 16×2 LCD mit I²C-Adapter

## Bibliotheken

- Wire
- LiquidCrystal_I2C

## Funktionen

- Zufällige Zahlen erzeugen
- Bubble Sort Schritt für Schritt
- Animation der Vergleiche auf dem LCD
- Benutzerdefiniertes LCD-Zeichen
